# Fundus für Word

Word-Add-in der Literaturverwaltung **Fundus** (Word für Mac und Windows).
Dieses Repository enthält nur die fertig gebaute Add-in-Seite, die über GitHub Pages
ausgeliefert wird: https://wildeswombat.github.io/fundus-word/

Deine Literatur liegt **nicht** hier: Das Add-in holt sie zur Laufzeit direkt aus der
Fundus-App auf deinem eigenen Rechner (`127.0.0.1`).

Einrichtung: in Fundus *Import & Export › Word-Add-in einrichten*, oder
[manifest.xml](manifest.xml) manuell in Word laden.
